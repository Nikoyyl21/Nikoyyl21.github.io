Focus & Expertise

核心关注方向

按方法族归档，不按产品名归档。基座与后训练合为一条主线，多模态重点讲视频与图像生成，评测作为横切维度单独列出；每条都写清方法、真实取舍，以及还没解决的问题。

01
Foundation Models / Post-training · Core

文本基座与后训练

  • 预训练与架构：MoE 专家路由与稀疏激活、数据配比与 mid-training 退火、RoPE 外推与 KV cache 成本
  • 后训练与对齐：DPO / PPO / GRPO 一族、RLVR 与可验证奖励、process reward model、扩散语言模型上的 RL 对齐（dLLM / EBPO）
  • 真实代价：reward hacking、KL 约束的取舍、scaling law 之外的数据墙
开放问题：后训练收益有多少来自基座能力本身，对齐代价与可验证奖励的泛化性怎么分开度量
02
Multimodal / Video & Image

多模态：视频与图像生成

  • 预训练数据：视频与图像语料的清洗去重、质量过滤与配比，时空一致性与运动标注、图文对齐；数据配比基本决定可控性上限
  • 生成结构：DiT 与 flow matching、时空 VAE 压缩比、长时序建模与分辨率外推，图像侧的控制分支与条件注入
  • 参考与编辑生成：reference-based 生成与主体 / ID 一致性、指令式编辑与局部重绘，Flow-GRPO / VideoReward 一类的奖励优化

语音作为共享表征下的另一路模态顺带覆盖，不单独展开。

开放问题：可控性与运动物理合理性，仍缺可靠的自动评测代理
03
Systems / Infra

Infra 与推理系统

  • 训练侧：TP / PP / EP 并行策略、MFU、训练稳定性
  • 推理侧：prefill-decode 分离、KV cache 与量化、SLO 下的单位 token 成本
  • 效率取舍：集群利用率与弹性调度、量化带来的精度损失
开放问题：集群规模、训练稳定性与推理成本之间的真实边界
04
Evaluation / Business Impact · Cross-cutting

评测与业务落地

  • 评测口径：可验证任务看 pass@k 与 RLVR，开放生成看人类偏好、LLM-as-a-judge 与 pairwise arena，视频看 VBench 与时序一致性；按业务场景拆，不套通用榜单
  • 业务落地：离线指标落到灰度 A/B、时延与单位成本、安全合规、人工抽检的回归集
  • 指标失真：judge 自偏好、benchmark 污染、评测集与真实分布偏移；榜单涨分不等于线上收益
开放问题：怎么把离线代理指标对齐到真实业务收益，并让评测结果反哺数据配比与训练
How I Read A Report

怎么读一份技术报告

这是我全部判断的依据，也是公开资料仓库的整理方式。

01

按方法族归档

同一条路线在不同实现里的差异，比发布顺序更有信息量。不按产品名堆清单。

02

多源交叉核验

OpenReview、arXiv、DBLP、机构主页和开源实现互相印证；同名歧义保留候选，不强行合并。

03

标注来源与置信度

每条判断都标来源。查不到就写查不到，不补推测，不把推断伪装成事实。
