# Petry · GitHub Pages 落地页

面向大模型算法研究员的单页式个人主页。点开链接直接看到定位、方向、方法论、人群、合作理由和联系方式，不需要滚动进 GitHub 的仓库列表。

## 文件结构

| 文件 | 作用 |
| :--- | :--- |
| `index.html` | 整页内容，所有文案都在这里 |
| `assets/site.css` | 浅蓝主题、深浅色适配、响应式布局 |
| `assets/site.js` | 移动端导航展开、滚动时高亮当前区块 |
| `assets/favicon.svg` | 站点图标 |
| `EDIT-ME.md` | 改稿清单 |

## 本地预览

直接用浏览器打开 `index.html` 即可，没有构建步骤、没有外部字体和 CDN 依赖。国内网络下加载不受影响。

## 上线方式

这是 GitHub 用户站点，仓库名必须是 `Nikoyyl21.github.io`，内容为 `main` 分支根目录下的 `index.html`。仓库创建并推送后，访问地址是 `https://nikoyyl21.github.io/`。

推送用已有的 SSH 密钥即可：

```
git push origin main
```

## 与 GitHub 个人主页的分工

| 地址 | 用途 |
| :--- | :--- |
| `https://nikoyyl21.github.io/` | 对外发的落地页，整页浅蓝、无 GitHub 导航栏，转化路径最短 |
| `https://github.com/Nikoyyl21` | GitHub 个人资料页，展示公开仓库和技术沉淀 |

外联邮件落款、签名、脉脉简介优先放落地页链接，GitHub 主页作为补充。两条路径都收敛到同一个动作：发一封邮件聊 15 分钟。

## 合规红线

1. 不写未授权客户名称、HC 细节、在招团队信息。
2. 不写任何候选人信息，不用「人才库」这类词。
3. 只写行业方向、公开论文里的技术判断和方法论。
4. 署名只用 Petry，不出现中文姓名和公司名。
