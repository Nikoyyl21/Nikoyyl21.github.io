# Petry · GitHub Pages 落地页

面向大模型方向研究员的单页式个人主页。点开链接直接看到定位、方向、自我介绍、和谁聊、常聊的一线团队、怎么聊和联系方式，不需要滚动进 GitHub 的仓库列表。

## 文件结构

| 文件 | 作用 |
| :--- | :--- |
| `index.html` | 整页内容，所有文案都在这里；文件开头是原创蜡笔涂鸦贴纸的 SVG `<symbol>` 定义 |
| `assets/site.css` | 浅绿主题、蜡笔贴纸布局、深浅色适配、响应式布局 |
| `assets/site.js` | 移动端导航展开、滚动时高亮当前区块、微信号一键复制、点击揭示电话号码弹窗、团队地图城市筛选 |
| `assets/favicon.svg` | 站点图标（手绘笑脸小太阳） |
| `EDIT-ME.md` | 改稿清单 |

贴纸全部是本地手绘 SVG 路径，没有外部图片、字体、CDN 或 JS 框架；国内加载不会开天窗，也不引用任何现成卡通角色。

## 本地预览

直接用浏览器打开 `index.html` 即可，没有构建步骤。国内网络下加载不受影响。

## 上线方式

这是 GitHub 用户站点，仓库名必须是 `Nikoyyl21.github.io`，内容为 `main` 分支根目录下的 `index.html`。仓库创建并推送后，访问地址是 `https://nikoyyl21.github.io/`。

推送用已有的 SSH 密钥即可：

```
git push origin main
```
